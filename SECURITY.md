# Security policy

## Reporting

Please use [GitHub private vulnerability reporting](https://github.com/siperonur/wolfpack/security/advisories/new) for a suspected vulnerability in public WolfPack material.

Do not include credentials, private operational topology, personal information, session data, or exploit details in a public issue. If private reporting is unavailable, open a minimal public issue requesting a private contact path without including sensitive details.

## Scope

This repository contains public architecture, documentation, and deliberately selected public material. The private operational WolfPack environment, credentials, recovery material, personal records, and sensitive infrastructure details are outside this repository and are not accepted as public disclosure material.

Security reports should identify the affected public path or behavior, expected impact, and safe reproduction information where possible.
